 # Day 1
 Introduction to IIOT,
IIoT stands for Industrial Internet of Things.

IIoT is the use of Internet of Things (IoT) technology in industries and factories. It connects machines, sensors, computers, and other industrial equipment to the internet so they can collect, share, and analyze data.

 # Example

In a factory, sensors can monitor a machine's

Temperature  

Pressure  

Speed  

Vibration  

Energy consumption  


This data is sent to a computer or cloud system. If the machine shows abnormal behavior, the system can alert the engineer before a major breakdown occurs.

# Main Components of IIoT  

. Sensors – Collect data from machines.  

. Connectivity – Transfers data through networks/Internet.  

. Cloud/Edge Computing – Processes and stores data.

 # Introduction to microsoft excel

Microsoft Excel is a spreadsheet software used to store, organize, calculate, analyze, and present data.

# Important Excel Terms
Term         	  Meaning
Workbook	  =  The complete Excel file  

Worksheet	 =  A single sheet/page inside a workbook  

Row	      =   Horizontal line, numbered 1, 2, 3...  

Column	   =   Vertical line, named A, B, C...  

Cell	     =   The intersection of a row and column  

Cell      =   Address	The name of a cell, such as A1 or B5  

Formula Bar = 	Used to enter or edit data and formulas  

Ribbon	    = The area containing Excel tools and commands
